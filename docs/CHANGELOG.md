# Changelog

The changelog lives at the repository root: **[`../CHANGELOG.md`](../CHANGELOG.md)**.

## Why this file is a pointer

This used to be a second copy. It drifted — it stopped being updated after
1.5.1 while the root file went on to 1.6.x — and a changelog that is a year
behind is worse than no changelog, because it answers the question confidently
and wrongly.

Nothing linked here. `README.md`, `pyproject.toml`'s `Changelog` URL, and
`CONTRIBUTING.md` all point at the root file, which is the one that is kept
current. Every entry this file used to hold is present there, verbatim.

Add new entries to the root `CHANGELOG.md` only. There is no second copy to
keep in sync any more, and that is deliberate.
