# fta_web -- web UI dependencies -- pip fallback
#
# The source of truth is the repo-root pyproject.toml, and the recommended
# install path is `uv sync --extra web --extra excel --extra ai` (see
# README.md). This file exists for the pip fallback and lists ONLY what the
# web layer adds; most of the vendored core's dependencies come from the
# repo-root requirements.txt:
#
#   openpyxl    -- Excel export (FTA_Editor_core)
#   openai      -- OpenAI provider (AI_agent_handler) -- identical package
#   anthropic   -- Anthropic provider (AI_agent_handler) -- identical package
#
# (Pillow is desktop-only: the web app's diagram renders as SVG in the
# browser and never touches PIL. See pyproject.toml's `desktop` extra.)
#
# google-genai is listed here, not in the root file, because it genuinely
# differs from the desktop app's Gemini dependency: fta_web/core/ai_providers.py
# migrated off the deprecated google-generativeai (divergence D11 in
# fta_web/core/DIVERGENCE.md); the frozen src/ai_providers.py did not and
# could not. Installing both files' requirements together installs both
# packages side by side, which is fine -- they serve different apps.
#
# Install both:
#   pip install -r requirements.txt -r fta_web/requirements.txt

Flask>=3.0.0
google-genai>=1.0.0

# Intentionally absent
# -------------------
# flask-session / any server-side session store: this is a single-user local
# tool whose entire state lives in one in-process object. Authentication is a
# per-launch token in a request header (see fta_web/security.py), not a cookie
# session -- a cookie would be attached automatically by the browser to a
# forged cross-site request, which is exactly the attack the token prevents.
#
# gunicorn / uwsgi / any pre-forking server: multiple workers would each hold a
# private copy of the editor state and silently lose edits. app.create_app()
# refuses to start under one.
#
# flask-cors: the API must be reachable from one origin only. Adding CORS
# headers would undo the anti-DNS-rebinding checks.
